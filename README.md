# 🔍 AzerClaw Search Plugin

Search plugin-i Yandex, Google və DuckDuckGo axtarış sistemlərində sorğu aparır.

## ✨ Xüsusiyyətlər

- Üç axtarış sistemində nəticə axtarır.
- Nəticə sayını sorğu ilə təyin etməyə imkan verir.
- API açarı tələb etmir.
- Xüsusi GUI interfeysi yoxdur; alətlər agent tərəfindən çağırılır.

## 📦 Quraşdırma

Pluginin ZIP faylını endirin. AzerClaw-da **Plugin yükləmə** bölməsinə daxil olun, endirdiyiniz ZIP faylını seçin və yükləyin. Pluginin asılılıqları varsa, AzerClaw onları avtomatik aşkarlayıb quraşdıracaq.

## 🚀 İstifadə

Plugin avtomatik olaraq AzerClaw tərəfindən aşkar edilir.

### Əmrlər

- `search.yandexSearch` — Yandex-də axtarır.
- `search.googleSearch` — Google-da axtarır.
- `search.duckDuckGoSearch` — DuckDuckGo-da axtarır.

Hər əmrdə nəticə sayı standart olaraq 10-dur.

## 📁 Fayl strukturu

- `main.js` — axtarış alətləri.
- `package.json` — plugin asılılıqları.
- `info.json` — plugin metadatası.

## 📦 Asılılıqlar

- `selenium-webdriver`
